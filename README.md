# AO3-Style Skin for SquidgeWorld

An unofficial site skin that makes SquidgeWorld look like AO3's default:
red header and footer, gray buttons, red titles, black dotted tags.

Not affiliated with AO3, the OTW, or Squidge.org.

## Install
1. Log in to SquidgeWorld, then Preferences > Skins > Create Site Skin
2. Paste the contents of `ao3-skin.css` into the CSS box
3. Under advanced options, choose "Use archive default as parent"
4. Click Preview, then Submit, then Use

## Known limitations
- The green SqW logo and default user icon are images, so CSS can't
  recolor them. Upload your own profile icon to replace the icon.
- Tested mainly on dashboard, profile, and work-blurb pages. Reading
  mode, forms, and the work editor may still have stray green/yellow.
  Issues and pull requests welcome!
